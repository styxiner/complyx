# Gestión de agentes

El listado de agentes permite buscar, filtrar y gestionar cada endpoint supervisado.

## Funcionalidades

- Búsqueda y filtrado por hostname, IP, SO, grupo y estado.
- Visualización de detalles técnicos: IP, OS, fecha de instalación, última conexión.
- Ver políticas asignadas y riesgos asociados al agente.
- Historial de ejecuciones de políticas.
- Acciones sobre el agente: activar/desactivar, desinstalar, modificar grupos/políticas.

!!! note "Rol requerido"
    Las acciones de modificación requieren rol **Administrador**. Técnicos y Auditores tienen acceso de solo lectura.
