# Dashboard

La vista principal muestra el estado global del cumplimiento normativo de la organización.

## Métricas mostradas

| Métrica | Descripción |
|---|---|
| Porcentaje de cumplimiento global | % de controles OK sobre el total |
| Agentes activos / inactivos | Conteo en tiempo real |
| Riesgos por nivel | Críticos, altos, medios, bajos |
| Evolución temporal | Gráfico de cumplimiento en el tiempo |

## Filtros disponibles

- Por **grupo** de agentes.
- Por **estado** del agente.
- Por **entorno** (producción, staging, etc.).
- Por **rango temporal**.

## Acceso por rol

| Rol | Acceso al dashboard |
|---|---|
| Administrador | Métricas completas + acciones |
| Técnico | Métricas de cumplimiento + generación de informes |
| Auditor | Solo lectura: métricas e informes |
