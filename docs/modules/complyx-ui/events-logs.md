# Eventos y logs

Registra todos los eventos relevantes del sistema con trazabilidad completa.

## Eventos mostrados

- Ejecuciones de políticas (con resultado: OK, FAILED, REMEDIATED).
- Remediaciones ejecutadas.
- Alertas de desviación.
- Cambios de estado de agentes.

## Filtros

- Por tipo de evento.
- Por agente o grupo.
- Por rango temporal.
- Por nivel de severidad.

## Exportación de evidencias

Los eventos se pueden exportar en **PDF o CSV** con timestamps e identificadores de agentes, listos para auditorías internas o externas.
