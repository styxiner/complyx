# complyx-ui

Interfaz gráfica construida con **Angular** y empaquetada con **Electron**, que permite su uso como PWA o aplicación de escritorio multiplataforma.

## Características

- Autenticación JWT con redirección automática ante token inválido.
- Renderizado dinámico de vistas según el rol del usuario (Administrador, Técnico, Auditor).
- Dashboard con métricas de cumplimiento, agentes activos y evolución temporal.
- Matriz de riesgos interactiva con filtros y acciones.
- Exportación de evidencias e informes en PDF/CSV.
- Diseño responsive compatible con navegadores modernos.
