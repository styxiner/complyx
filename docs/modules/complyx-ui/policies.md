# Gestión de políticas

La sección de políticas permite gestionar los documentos de control de seguridad aplicados a los agentes.

## Funcionalidades

- Consultar, filtrar y buscar políticas por nombre, severidad y versión.
- Subir y editar el JSON de política con validación en tiempo real.
- Ver los controles y normativas asociadas a cada política.
- Ver los riesgos mitigados por cada política.
- Asignar políticas a agentes o grupos.

## Severidades

| Nivel | Color |
|---|---|
| `critical` | :red_circle: Rojo |
| `high` | :orange_circle: Naranja |
| `medium` | :yellow_circle: Amarillo |
| `low` | :green_circle: Verde |
