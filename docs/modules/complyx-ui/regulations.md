# Normativas

La sección de normativas permite gestionar los marcos regulatorios de referencia.

## Funcionalidades

- Cargar y visualizar PDFs de normativas (ISO 27001, ENS, NIS2 y otras).
- Navegar entre normativas, secciones y políticas asociadas.
- Ver qué controles de políticas están mapeados a cada sección normativa.
- Descargar el PDF original de la normativa.

## Navegación entre entidades

```
Normativa → Sección → Control (policy_check) → Política → Agente
```
