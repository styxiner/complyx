# Informes de cumplimiento

Generación y descarga de informes de cumplimiento directamente desde la interfaz.

## Tipos de informes

| Tipo | Descripción | Formato |
|---|---|---|
| Resumen global | % cumplimiento general de la organización | PDF / JSON |
| Detallado por agente | Resultado de cada control por endpoint | PDF |
| Por normativa | Controles mapeados a ISO/ENS/NIS2 | PDF |
| Evidencias de auditoría | Log completo de ejecuciones con trazabilidad | PDF / CSV |

## Acceso por rol

- **Técnico**: genera y descarga informes de cumplimiento resumidos y detallados.
- **Auditor**: accede a todos los informes y puede exportar evidencias de auditoría.
