# Matriz de riesgos

La matriz de riesgos muestra el impacto por probabilidad de los riesgos detectados en los agentes.

## Vista de la matriz

Los riesgos se posicionan en una cuadrícula 2D según su **impacto** (eje Y) y **probabilidad** (eje X), con colores que indican el nivel de riesgo resultante.

## Acciones disponibles

Sobre cada riesgo se pueden realizar las siguientes acciones (rol **Administrador**):

| Acción | Descripción |
|---|---|
| **Aceptar** | El riesgo se acepta de forma consciente y documentada |
| **Transferir** | Se transfiere la responsabilidad (ej. a un seguro) |
| **Cerrar** | El riesgo se ha mitigado completamente |

## Filtros

- Por nivel de riesgo (crítico, alto, medio, bajo).
- Por estado (abierto, aceptado, transferido, cerrado).
- Por agente o grupo.
